# Print Materials & Sales Collateral Suite

This directory contains print-ready, high-resolution HTML/CSS collateral templates for **Harley Digital Works** and **The Harley Group**.

All documents are pre-formatted for standard **A4 portrait printing** (`@page { size: A4 portrait; margin: 12mm; }`), using the approved brand palettes and typography.

## How to Export to PDF

1. Open any `.html` template in Google Chrome, Edge, or Safari.
2. Press `Ctrl + P` (or `Cmd + P` on Mac).
3. Set **Destination**: _Save as PDF_.
4. Set **Layout**: _Portrait_.
5. Set **Paper Size**: _A4_.
6. Check **Background graphics**: _Enabled_.
7. Click **Save**.
