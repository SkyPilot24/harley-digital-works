# Daily Agency Playbook

Use this as the simple operating rhythm for THG Digital Agency.

## Daily steps

1. Check new leads and reply within one working day.
2. Send one sales or follow-up message.
3. Create or improve one useful content asset.
4. Use Manus for one research or prospecting task.
5. Review Diagnostics and Revenue OS for the next best action.

## Tool use

- Manus: research, competitor scans, prospect lists, repeatable browser tasks.
- ChatGPT: sales replies, offers, landing page copy, SOPs, client explanations.
- Google AI Pro: longer drafts, research synthesis, content expansion, Google Docs style working.

## Rule

If an action does not help get leads, close clients, deliver projects, or improve trust, leave it for later.
## Revenue stream checklist

- Web Services: one targeted website improvement note per day.
- Care Plans: attach recurring support to every website conversation.
- AI Automation: document one repeated workflow and package it as an audit example.
- Content Engine: turn one client question into a useful post or resource.
- Digital Products: convert one internal template into a sellable asset.
- Domains: write one buyer/use-case/outreach list for one domain.
- YouTube: validate one title, script, or offer CTA.
- SaaS: record one Control Centre feature that could become a product.
