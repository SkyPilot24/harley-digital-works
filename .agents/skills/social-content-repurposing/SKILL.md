# Social Content Repurposing

## When to Use

- Adapting one core asset into multiple social formats
- Building platform-specific hooks and post variants
- Structuring a repeatable publishing cadence

## Outputs

- Channel-specific post ideas from one source asset
- Hook and angle variants mapped to audience intent
- Draft social calendar grouped by goal and platform

## Guidance

- Preserve core message while adapting format per channel
- Match platform norms for tone, length, and CTA style
- Prioritize consistency and reuse efficiency
