# Harley SEO Map-Pack Radar Skill

## Overview
Analyzes local search performance across 25-point geo-grids for UK trade contractors, identifying high-intent search queries and citation gaps.

## Key Checkpoints
1. Google Business Profile primary and secondary categories.
2. LocalBusiness JSON-LD schema on contractor homepage.
3. 25 high-authority UK trade directory citations (Yell, Thomson Local, Checkatrade, TrustATrader).
4. Automated 5-Star SMS review capture loops.
