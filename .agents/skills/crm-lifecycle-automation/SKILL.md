# CRM / Lifecycle Automation

## When to Use

- Designing lead nurture and onboarding journeys
- Building retention and win-back flow strategies
- Defining segmentation and trigger logic

## Outputs

- Lifecycle flow map by stage and audience segment
- Trigger and message sequencing recommendations
- Prioritized automation opportunities by expected impact

## Guidance

- Start with high-intent lifecycle moments
- Use clear segment definitions tied to behavior
- Optimize for both engagement and downstream conversion quality
