# Website Care Plan Management

## When to Use
- Managing client Care Plan tiers (£95/mo Launch Care, £195/mo Growth Care, £395/mo Pro Care).
- Executing routine monthly maintenance checklists (uptime, speed, SSL renewal, dependency audits).
- Handling client change requests received via WhatsApp, email, or ticketing (same-day SLA).
- Generating monthly client value reports (traffic overview, uptime, security status, changes completed).

## Care Plan Operational Standards

### 1. SLA & Response Times
- **Urgent Incidents (Site Down / Form Broken)**: < 2 hours response, immediate triage.
- **Standard Edits (Text/Photo changes, price updates, new reviews)**: < 24 hours turnaround.
- **Channel**: Allow clients to submit changes via WhatsApp voice note, text, or simple email.

### 2. Routine Maintenance Schedule
- **Weekly**: Automated off-site database and asset cloud backups verified.
- **Monthly**: Framework and dependency security patches tested in staging before zero-downtime production deployment.
- **Quarterly**: Core Web Vitals performance audit (aiming for 90+ mobile Lighthouse score) and broken link checks.

### 3. Client Retention & Value Delivery
- Every month, send a simple 3-point plain-English email digest:
  1. *“Your website was online 100% of the time with 0 security issues.”*
  2. *“We updated [X changes requested].”*
  3. *“Your site received [Y] visitor sessions and [Z] quote submissions this month.”*
