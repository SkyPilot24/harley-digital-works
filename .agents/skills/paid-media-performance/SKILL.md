# Paid Media Performance

## When to Use
- Diagnosing campaign underperformance
- Reallocating budget across channels, audiences, and campaigns
- Planning creative testing frameworks

## Outputs
- Channel and campaign performance diagnosis
- Budget reallocation recommendations with rationale
- Structured test backlog for creatives, audiences, and offers

## Guidance
- Prioritize actions by expected incremental return
- Separate tracking issues from true performance issues
- Recommend changes that can be validated quickly
