# Technical SEO + Web Performance

## When to Use
- Investigating crawl, indexation, and rendering issues
- Prioritizing Core Web Vitals improvements
- Identifying structured data and technical SEO opportunities

## Outputs
- Prioritized technical SEO issue list with severity
- Web performance actions mapped to CWV impact
- Implementation-ready recommendations for indexing and schema

## Guidance
- Prioritize fixes that improve both visibility and conversion
- Separate critical blockers from incremental enhancements
- Consider rollout risk before recommending broad technical changes
